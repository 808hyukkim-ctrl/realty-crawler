온하우스 매물수집기 (단독 실행 버전)  — 2026-09-11 빌드
=====================================================

■ 실행
  온하우스매물수집기_독립버전.exe 더블클릭
  (onefile 압축 해제 때문에 첫 실행은 5~20초 걸릴 수 있습니다)

■ 계정
  - 유료 회원사 계정 필요. 무료 계정은 목록만 보이고 상세(주소/가격/면적)와 연락처가 막힙니다.
  - "아이디/비밀번호 저장" 체크 시 exe 옆에 onhouse_credentials.json 으로 저장됩니다. (예약 실행에는 저장 필수)

■ 지역 (다중 선택)
  시/도 · 시군구 · 읍면동 각 칸이 체크박스 목록입니다. 여러 개를 동시에 체크할 수 있습니다.
  - 시/도를 체크하면 그 시/도들의 시군구가 아래 칸에 뜨고, 시군구를 체크하면 읍면동이 뜹니다.
  - 규칙: 가장 아래 단계에 체크가 있으면 그것만 수집, 없으면 그 위 단계 선택 전체를 수집.
      예) 서울 체크 + 강남구·서초구 체크 + 읍면동 전체     → 강남구·서초구 모든 동
          서울 체크 + 강남구 체크 + 역삼동·논현동 체크      → 역삼동·논현동만
          서울·경기 체크, 나머지 전체                        → 서울·경기 모든 동 (매우 오래 걸림)
  - 오른쪽에 "선택 지역 N개"로 실제 수집 지역 수가 표시됩니다.

■ 유형 / 기간
  - 거래유형: 월세 / 전세 / 매매 체크 (여러 개 가능), 방유형(주택·오피·사무실·상가 등) 선택
  - 확인일(업로드) 기간: 전체 / 오늘 / 어제~오늘 / 최근 3일 / 최근 7일 / 최근 30일 / 직접 지정(시작~종료)
      · 온하우스 목록의 "확인일"(매물 등록·갱신 확인 시각) 기준입니다.
      · 목록이 확인일 최신순으로 오기 때문에, 기간보다 오래된 매물이 나오면 그 지역은 더 넘기지 않아
        빠르고 서버 요청도 적습니다. 엑셀에 "확인일" 컬럼이 들어갑니다.

■ 수집 옵션
  - 임대인 연락처도 수집
      · 온하우스 서버가 계정별 "잔여 연락처 조회수"를 관리합니다 (실측: 새 매물 1건 조회 = 1 차감,
        같은 매물 재조회 = 차감 없음). 이 차감은 서버가 하는 것이라 프로그램에서 없앨 수 없습니다.
      · 한 번 조회한 연락처는 exe 옆 onhouse_contacts_cache.json 에 저장해두고 다음부터 캐시를 씁니다
        → 같은 매물로 조회수가 다시 나가지 않습니다.
      · 시작 시 "현재 잔여 연락처 조회수: 임대 N건 / 매매 M건", 종료 시 "신규 조회 n건 / 캐시 재사용 m건 / 잔여"
        가 로그에 찍힙니다. 연락처는 대부분 050 안심번호(가상 중계번호)로 나옵니다.
      · 조회 실패가 5회 연속이면(조회수 소진 등) 연락처 수집만 자동 중단하고 매물 수집은 계속합니다.
  - 요청 간 대기(초)      : 기본 2~5초 랜덤. 서버 부담/계정 차단 위험을 줄입니다. 줄이지 않는 걸 권장.
  - 지역당 최대 페이지    : 0=제한없음. 30건/페이지. 시험 삼아 돌릴 때 1~2로 두세요.

■ 예약 자동 실행
  1. 화면에서 지역·유형·기간·옵션을 원하는 대로 맞춘 뒤 [현재 설정으로 예약 추가]
  2. 예약 이름, 실행 시각(HH:mm), 요일(매일 또는 개별 요일) 지정 → 저장
     → 그 시점의 화면 설정이 예약에 통째로 저장됩니다 (목록에 마우스를 올리면 조건이 보임)
  3. 예약은 여러 개 등록 가능 (예: 09:00 강남 전체, 13:00 서초 오늘 것만, 18:00 마포 연락처 포함)
  4. [선택 켜기/끄기] 로 일시 중지, [선택 예약 지금 실행] 으로 즉시 테스트, [선택 삭제] 로 제거
  ※ 주의
     - 이 프로그램이 켜져 있어야 실행됩니다. (창을 닫으면 예약도 멈춤 — 최소화는 괜찮음)
     - 15초마다 시각을 확인하며, 같은 예약은 하루 1번만 실행됩니다.
     - 실행 시각에 다른 수집이 돌고 있으면 그 예약은 건너뛰고 로그에 남깁니다.
     - 예약 정보는 exe 옆 onhouse_schedules.json 에 저장됩니다.
     - 예약 실행은 확인 팝업 없이 바로 시작하므로, 연락처 옵션이 켜진 예약은 조회수가 매일 차감됩니다.

■ 수집 완료 후 자동 전송  (2026-09-21 추가)
  수집이 끝나면 저장된 엑셀을 메일과 텔레그램으로 자동 발송합니다. 예약 수집 결과도 똑같이 옵니다.
  설정은 exe 옆 onhouse_send.json 에 저장되어, 한 번만 입력하면 다음부터 그대로 씁니다.

  - 메일로 보내기
      1) 보내는 지메일 계정에서 2단계 인증을 켭니다.
      2) 구글 계정 > 보안 > 앱 비밀번호 에서 16자리를 발급받아 '앱 비밀번호' 칸에 넣습니다.
         (평소 쓰는 비밀번호는 구글이 막습니다)
      3) 받는 사람은 여러 명이면 쉼표로 구분합니다.
      · 첨부 용량 한도 25MB. 넘으면 텔레그램으로 받으세요.

  - 텔레그램으로 보내기
      1) 텔레그램에서 @BotFather 에게 /newbot 을 보내 봇을 만들고 토큰을 받습니다.
      2) 만든 봇과의 대화방에 아무 메시지나 한 번 보냅니다.
      3) 프로그램에서 토큰을 넣고 [챗 ID 찾기]를 누르면 챗 ID가 자동으로 채워집니다.
      · 엑셀 파일이 그대로 첨부되어 옵니다. 폰에서 바로 열립니다. 한도 50MB.
      · 여러 명이 같이 받으려면 그룹방을 만들어 봇을 초대한 뒤 그 방의 챗 ID를 넣으세요.

  - [테스트 전송] 버튼으로 설정이 맞는지 먼저 확인하세요. 결과는 로그에 찍힙니다.
  - 둘 다 무료입니다. 전송 실패해도 수집한 엑셀은 data 폴더에 그대로 남습니다.

■ PC를 꺼둬도(자고 있어도) 자동 수집  (2026-09-21 추가)
  프로그램을 띄워두지 않아도 윈도우가 정해진 시각에 프로그램을 실행합니다.
  자고 있던 PC는 스스로 깨어나고, 수집·전송이 끝나면 프로그램이 알아서 닫힙니다.

  [준비]  프로그램에서 먼저 세 가지를 해두세요.
    1. 아이디/비밀번호 저장 체크 (무인 실행에는 필수)
    2. 예약을 하나 이상 만들기 — 수집 조건이 예약에 통째로 저장됩니다.
       (여기서 정한 예약 시각은 무인 실행에서는 쓰이지 않습니다. 켜져 있는 예약을 순서대로 다 돌립니다)
    3. 자동 전송 칸에 메일 또는 텔레그램 입력 + 테스트 전송으로 확인

  [등록]  자동실행_설정.bat 을 실행 → 관리자 권한 허용 → 시각 입력(예: 08:30)
    · 매일 그 시각에 실행되도록 윈도우 작업 스케줄러에 등록합니다.
    · '깨우기 타이머'도 같이 켭니다. 그래야 자는 PC가 깨어납니다.
    · 마지막에 y 를 누르면 지금 한 번 시험 실행해 봅니다.

  [해제]  자동실행_해제.bat 실행

  ※ 주의
    - 전원을 완전히 끄면(종료) 깨어나지 못합니다. 퇴근할 때 그냥 두거나 절전으로 두세요.
    - 노트북은 덮개를 닫아도 되지만 전원 어댑터를 꽂아두는 편이 안전합니다.
    - 다른 PC에서 쓰려면 이 폴더를 통째로 복사한 뒤, 그 PC에서 자동실행_설정.bat 을 한 번 실행하세요.
      (설정 파일들이 exe 옆에 있어 계정·예약·전송 설정이 같이 따라갑니다)
    - 수동으로 창을 띄워 쓰던 방식도 그대로 됩니다.
